Como funciona

  1. Entrada do carro: placa, cliente e o que ele relatou. Leva 20 segundos.
  2. Link pelo WhatsApp: o cliente acompanha cada etapa sem precisar ligar.
  3. Orçamento no celular: o cliente marca o que quer fazer e aprova com um toque. Fica registrado.
  4. Pronto: aviso automático para retirar e, meses depois, o lembrete da revisão.

É isso que o cliente abre no celular pelo link que chega no WhatsApp. Não precisa baixar aplicativo nem criar senha.
